# Happy Life — для людей (коротко)

**Сайт:** [happylife.estate](https://happylife.estate)

**Без реєстрації:** на головній сторінці — **«Спробувати демо»** (кабінет власника з прикладами, без пароля).

У додатку відкрийте **Ще → Як користуватися** — там той самий текст українською (і ru / en у перемикачі мови). Нижче — копія для друку або чату КГ.

---

**Навіщо.** Офіційні справи КГ в одному місці: заявки, новини, голосування, платежі по будинку. Не треба шукати в Viber, хто скільки платить і що з вашим зверненням.

**Чим допомагає.**

- Заявки не губляться — є статус.
- Новини та голосування бачать усі однаково.
- Платежі — коли голова надіслав рахунок по вашому будинку.
- Документи КГ — не в пошті.

**Кнопки внизу:** Головна · Заявки · Спільнота · Ще (платежі, профіль).

**Червона цифра** — щось нове. Відкрийте саме ту картку — цифра зникне.

**Це не заміна чату сусідів** — для швидких питань чат лишається.

Питання — **голові КГ**.
