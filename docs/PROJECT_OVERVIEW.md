# Happy Life — описание проекта

## Позиционирование

Веб-платформа (с перспективой мобильного приложения) для **коммуникации и совместной жизни** жителей коттеджных посёлков и ОСББ (ориентация на **Украину**, валюта интерфейса — **гривня**): новости, учёт, заявки в управляющую компанию / совет, голосования, доска объявлений и структурированные обсуждения между соседями. Интерфейс — **украинский**, **английский** и **русский** (в переключателе языка — метка **«Київський»**).

## Проблема

Разрозненные чаты (WhatsApp, Telegram), Excel и «устные договорённости» приводят к потере важных сообщений, непрозрачности решений и конфликтам. Нужен **один вход** для официальной информации, личных дел (счётчики, взносы) и соседского обмена без полной замены мессенджеров, но с лучшей структурой.

## Целевая аудитория

- **Жители** — ежедневное использование: напоминания, объявления, заявки, голосования, доска и тематические обсуждения.
- **Председатель / администрация** — публикации, запуск голосований, работа с заявками, финансовые/учётные данные (в объёме MVP — поэтапно).
- **Модератор** — модерация анонимных обращений и при необходимости контента сообщества.

## Функциональные модули (по исходному видению)

| Модуль | Назначение |
|--------|------------|
| **Главная (Dashboard)** | Центр: новости, быстрые действия, активные голосования, мои заявки, напоминания (взносы, счётчики). |
| **Счётчики / коммуналка** | Подача показаний, история, начисления, баланс/задолженность, напоминания. |
| **Заявки (Service Desk)** | Категории (дороги, освещение, охрана, вода, мусор…), фото, геометка, статусы, «мои» и при необходимости общий список по посёлку. |
| **Голосования** | Активные/архив, типы (да/нет, множественный выбор, опрос), результаты. |
| **Анонимные обращения** | Для соседей — анонимно; для модератора — автор виден; статусы рассмотрения. |
| **Доска объявлений** | Продам/отдам, услуги, рекомендации, потеряно/найдено. |
| **Чат/форум (Threads-like)** | Темы и ветки обсуждений, много параллельных тем. |

## Роли

- **Житель** — полный доступ к функциям потребителя.
- **Модератор** — расширенные права, в т.ч. анонимные обращения.
- **Председатель** — заявки, новости, голосования, обновление задолженностей (и связанные административные действия).

## User flow (MVP)

`Регистрация → подтверждение адреса дома → главная → использование модулей`

## Границы MVP (зафиксировать на старте)

Рекомендуется явно разделить:

- **MVP-ядро:** регистрация + верификация адреса, главная лента действий, заявки, голосования (минимальный набор), объявления, одна модель чата/тем.
- **Следующие итерации:** полная финансовая автоматизация, интеграции оплаты, сложная модерация, мобильные push-платформенно.
