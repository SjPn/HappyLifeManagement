# Happy Life — руководство для тестирования

Краткое описание для людей, которые **впервые** видят продукт. Перед отправкой тестировщикам заполните блок «Доступ» в разделе 7.

**Сайт (прод):** [https://hlm-nu.vercel.app](https://hlm-nu.vercel.app)  
**Что это:** единый портал для **КГ** — новости, заявки в управление, голосования, соседи, платежи (учёт). Это не замена Telegram/WhatsApp, а **структурированный «официальный вход»** в жизнь КГ.

**Язык интерфейса:** переключатель **UA / RU / EN** (рекомендуем **RU**).  
**APK:** та же система в оболочке Android (актуальная сборка с **кнопкой «Назад»** системы — скачайте заново из **Ещё**). После установки полностью закройте и откройте приложение, если был сбой.

---

## 1. Кто пользуется и зачем

| Роль | Кто это | Главное в системе |
|------|---------|-------------------|
| **Житель** | Собственник или арендатор дома | Заявки, голосования, доска, форум, платежи, сообщения |
| **Глава** | Председатель / администрация КГ | Новости, голосования, все заявки, жители, тарифы, начисления по месяцам |
| **Модератор** | Служебная роль | Пользователи + **конфиденциальные обращения** (автора видит только модератор) |
| **Админ платформы** | Владелец SaaS (не КГ) | Отдельная панель `/platform` — для теста КГ **не нужна** |

Один КГ = **одно «сообщество»** в системе. Данные разных КГ **не смешиваются**.

---

## 2. Как войти

1. Откройте сайт → **Войти** или **Регистрация**.
2. **Новый житель:** нужен **код приглашения** от главы КГ + email, пароль, адрес (улица/дом), статус **собственник / арендатор**.
3. После регистрации статус **«Ожидает подтверждения»** — пока глава не подтвердит адрес, полный доступ закрыт.
4. Язык: переключатель **UA / RU / EN** (обычно в **Ещё** → блок приложения).
5. **Мобильное приложение (необязательно):** **Ещё** → «Скачать приложение (APK)» — тот же сайт в оболочке Android.

> **Организатор теста:** HAPPY2026

## 4. Бизнес-логика по модулям

### 4.1. Заявки (главный сценарий)

**Житель:** Заявки → **Новая заявка** → категория (дороги, освещение, охрана, вода, мусор, другое), описание, фото по желанию.

**Статусы:** `Новая` → `В работе` → `Решено`.

**Глава / модератор:** открывает заявку в списке → меняет статус, может комментировать. После `Решено` **автор** может поставить оценку 1–5.

**Ожидание теста:** житель создал → у главы появилась заявка → смена статуса → у жителя обновился статус (и в «Сейчас важно» на главной).

### 4.2. Голосования

**Глава** создаёт голосование (да/нет или варианты), может ограничить **аудиторию**: все / только собственники / только арендаторы.

**Житель** голосует, если его статус проживания подходит под аудиторию.

После дедлайна — просмотр результатов, архив.

### 4.3. Сообщество

| Раздел | Кто публикует | Суть |
|--------|----------------|------|
| **Новости** | Глава | Официальные объявления для всех |
| **Доска** | Жители | Продам/услуги/рекомендации/найдено |
| **Форум** | Жители | Темы и ответы (обсуждения) |
| **Жители** | Каталог | Кто в КГ (после подтверждения) |
| **Сообщения** | 1-на-1 | Личный чат между подтверждёнными жителями |
| **Документы** | Глава загружает | Файлы для всех (правила, протоколы) |

### 4.4. Платежи (`/payments`)

Учёт **на дом**, не на человека: абонплата + электроэнергия за месяц.

**Глава:**

1. Раскройте блок **«Тарифы и реквизиты»** — один раз задайте **дневной/ночной тариф** (₴/кВт·ч) и **реквизиты** для оплаты.
2. По каждому дому за выбранный месяц: введите **показания счётчика** (день/ночь) → **«Рассчитать и сохранить»** — сумма электроэнергии подставится автоматически.
3. Проверьте абонплату и электроэнергию → кнопка **«Отправить»** (не «Сохранить») — жителю уходит начисление; на карточке появится **«Отправлено жителю»**.
4. Можно копировать начисления с прошлого месяца; отметить **«Оплачено»**, когда дом заплатил.

**Житель:** видит начисления своего дома, реквизиты, расшифровку по счётчику (если глава внёс показания), кнопку копирования реквизитов.

Онлайн-оплаты в системе **нет** — только информирование и учёт.

### 4.5. Конфиденциальные обращения

Житель подаёт **анонимно** для остальных; **модератор** видит автора и меняет статус рассмотрения. **Глава** эти обращения **не видит** (так задумано).

Путь модератора: **Управление** → раздел отчётов/модерации.

### 4.6. Глава — панель «Управление» (`/chair`)

Типичные пункты:

- **Жители** — подтвердить/отклонить адрес, редактировать профили, баланс.
- **Адреса** — справочник улиц/домов для регистрации.
- **Заявки, голосования, новости** — через те же модули, что и в меню.
- **Тарифы / меморандум** — тексты для КГ.
- **Код приглашения** — в **Ещё** (для новых жителей).

## 5. Рекомендуемый сценарий теста (30–45 мин)

### Роль «Житель»

1. Войти (или зарегистрироваться с кодом → дождаться подтверждения).
2. Главная — посмотреть «Сейчас важно».
3. Создать **заявку** с фото.
4. **Сообщество** → доска или форум — один пост.
5. **Платежи** — посмотреть месяц, реквизиты.
6. Если есть активное **голосование** — проголосовать.

### Роль «Глава»

1. Подтвердить нового жителя (если регистрировались под тест).
2. Опубликовать **новость**.
3. Открыть **заявку** жителя → статус «В работе» → «Решено».
4. Создать **голосование** (аудитория «все»).
5. **Платежи** — тарифы в блоке «Тарифы и реквизиты», показания счётчика, **Отправить** жителю.

### Роль «Модератор» (если есть)

1. Войти → **Управление**.
2. Просмотреть **конфиденциальное обращение** (если житель создал).
3. Убедиться, что **нельзя** публиковать новости/голосования как глава.

## 6. На что обратить внимание (баги / UX)

- На вложенных экранах (тарифы, меморандум, голосование, новая заявка) есть ли **кнопка «← Назад»** вверху и работает ли **системная «Назад»** на Android (в новом APK).
- Удобно ли на **телефоне** (нижнее меню, модалки, формы).
- Понятны ли **статусы заявки** и кто что видит.
- Корректен ли **язык** (UA/RU/EN).
- Загрузка **фото** в заявках/новостях.
- После действий другой роли — обновляются ли списки (иногда нужно обновить страницу).
- **Ещё** → APK: скачивается и ставится; на рабочем столе **синяя иконка с домом** (не зелёная «C» Capacitor).
- **Push:** в **Ещё** может быть текст, что уведомления временно отключены — это нормально; **не** ждите запрос разрешений (иначе был вылет до исправления).

## 8. Ограничения версии (не баг)
