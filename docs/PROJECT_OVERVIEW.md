# Happy Life — описание проекта

## Позиционирование

Веб-платформа и **Android APK** (Capacitor) для **коммуникации и совместной жизни** в **коттеджных городках (КГ) и ОСМД** (Украина, **гривна**): новости, заявки, голосования, соседи, учёт платежей. Интерфейс: **украинский**, **русский**, **английский** (переключатель **UA / RU / EN**).

## Проблема

Разрозненные чаты (WhatsApp, Telegram), Excel и устные договорённости → потеря сообщений и непрозрачные решения. Нужен **один официальный вход**, без полной замены мессенджеров.

## Целевая аудитория

- **Жители** — заявки, голосования, доска, форум, платежи, сообщения.
- **Глава (председатель)** — новости, голосования, заявки, жители, тарифы, начисления.
- **Модератор** — пользователи и конфиденциальные обращения (автора видит только он).

## Функциональные модули

| Модуль | Назначение |
|--------|------------|
| **Главная** | Новости, **«Сейчас важно»** (заявки, платёж, голосование), напоминание о долге |
| **Заявки** | Service desk: категории, фото, статусы, архив, оценка после закрытия |
| **Голосования** | Да/нет, варианты, аудитория (все / собственники / арендаторы) |
| **Сообщество** | Новости, доска, форум, жители, документы, ЛС 1-на-1 |
| **Платежи** | Начисления **на дом** по месяцам, реквизиты, без онлайн-оплаты |
| **Конфиденциальные обращения** | Анонимно для соседей; модератор видит автора |

## Роли

- **Житель** — `OWNER` / `TENANT`; видимость части голосований/форума по аудитории.
- **Глава** — публикует новости, управляет заявками и биллингом; видит весь контент.
- **Модератор** — жители + конфиденциальные обращения; **не** публикует новости и **не** голосует как житель.

**Платформа:** `/platform/communities` — суперадмин (не для пилота КГ).

## User flow

`Регистрация с кодом → подтверждение адреса главой → главная → модули`

## Границы MVP

- **Ядро (есть):** multi-tenant, заявки, голосования, сообщество, платежи, APK с иконкой.
- **В работе / план:** Telegram-уведомления, push (FCM после Firebase), онлайн-оплата, release APK.
