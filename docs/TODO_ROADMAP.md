### 4. Telegram — логика (простыми словами)

**Это не замена сайта**, а уведомления снаружи — как у [Мій Дім](https://miidimonline.ua/mistechka): без push в APK люди редко заходят в приложение; Telegram уже есть у всех.

| Событие в Happy Life | Кому в Telegram |
| --- | --- |
| Новая заявка | Голова: «Нова заявка від …» |
| Статус заявки изменился | Житель (если подписан): «Ваша заявка: В роботі» |
| Новость от главы | Жители с opt-in: короткий текст + ссылка |
| Напоминание о долге (раз в N дней) | Житель с долгом |

**Привязка:** в профиле «Підключити Telegram» → бот → `/start КОД_ПОСЕЛКА` → сохранить `telegramChatId` в БД. Голова — почти всегда в боте (новые заявки).

**Реализация (следующая итерация, ~2–3 дня):** отдельный мини-сервис (BotFather + webhook), поля в Prisma, opt-in в профиле, вызовы из server actions при смене статуса заявки / публикации новости / cron долга.

- [ ] Telegram-бот: webhook-сервис, `telegramChatId`, opt-in, события из таблицы выше.
- [ ] WhatsApp — только если появится бизнес-нужда (дороже и сложнее API).

### Уведомления: Telegram vs Push в APK

| | Telegram-бот | Web Push / FCM в Capacitor |
| --- | --- | --- |
| Охват | Все с Telegram, без установки APK | Только установившие APK и разрешившие уведомления |
| Сложность | Отдельный сервис + webhook (~2–3 дня) | FCM: Firebase, ключи, плагин `@capacitor/push-notifications`, обработка токенов в БД |
| WebView (сайт в браузере) | Работает одинаково | Web Push возможен, но на Android в WebView/Capacitor ненадёжно без нативного FCM |
| Стоимость | Бесплатно (лимиты Telegram) | Firebase бесплатно; SMS — отдельный провайдер |

**Рекомендация для пилота:** сначала Telegram (быстрее, как у конкурентов). Push в APK — **фаза 5b**, если поселок настаивает «только из иконки приложения»: Capacitor + FCM + хранение `devicePushToken` рядом с `telegramChatId` (можно оба канала).
