# Happy Life — як користуватися

**Сайт:** [https://happylife.estate](https://happylife.estate)  
**Мови:** українська · російська · English (перемикач у шапці)

Happy Life — офіційний веб-портал вашого **котеджного містечка / ОСМД**. Це не заміна Viber або Telegram, а **одне місце**, де зберігаються рішення, заявки, новини та платежі по будинку.

---

## Які проблеми вирішує

| Було | Стало в Happy Life |
|------|-------------------|
| Заявки губляться в чатах | Кожна заявка з номером, статусом і історією |
| Новини голови — у стрічці месенджера | Розділ «Новини» — усі бачать однаково |
| Платежі — в Excel або на словах | По будинку: тарифи, лічильники, «відправлено» / «оплачено» |
| Голосування — папір або опитування в чаті | Офіційні опитування з терміном |
| Документи КГ — у пошті | Архів документів на сайті |
| Незрозуміло, хто сусід по вулиці | Каталог домогосподарств (за згодою КГ) |

## Хто користується

| Роль | Що робить |
|------|-----------|
| **Житель** | Подає заявки, читає новини, голосує, бачить свої платежі, форум |
| **Голова** | Підтверджує реєстрації, керує заявками, публікує новини, вносить тарифи та показання лічильників |
| **Модератор** | Допомагає з контентом і заявками (за налаштуванням КГ) |

Код запрошення до вашого КГ видає **голова** — його не публікують у відкритому доступі.

## Перший вхід

1. Відкрийте [happylife.estate](https://happylife.estate).
2. **Реєстрація** — введіть код запрошення, ПІБ, email, пароль, адресу (вулиця / будинок зі списку КГ).
3. Дочекайтесь **підтвердження** від голови (статус «очікує»).
4. Після підтвердження — **увійти** з email і паролем.

Якщо вже є обліковий запис — лише **Увійти**.

## Навігація (житель)

Внизу екрана чотири розділи:

| Розділ | Зміст |
|--------|--------|
| **Головна** | Новини, короткий огляд |
| **Заявки** | Ваші звернення до голови (дороги, вода, безпека…) |
| **Спільнота** | Сусіди, голосування, форум |
| **Ще** | Платежі, документи, повідомлення, профіль, **завантаження APK** |

**Червона цифра** на іконці — є нове з моменту вашого останнього візиту (наприклад, нова заявка або надісланий рахунок).

### Заявки

1. Створити заявку → категорія + опис (+ фото за потреби).
2. Слідкувати за статусом: *Нова* → *В роботі* → *Вирішено*.
3. Коментарі в картці заявки.

### Платежі

- Показання **лічильника** (день / ніч) — внести до дедлайну, якщо голова відкрив період.
- Після того як голова **надіслав** нарахування — з’являється сума по будинку; позначте **«Оплачено»**, коли переказали кошти (офлайн, без оплати карткою на сайті).

### Голосування та форум

- У **Спільноті** — активні опитування та теми форуму.
- Голосування мають термін завершення.

## Навігація (голова)

Ті самі розділи, плюс інструменти керування:

| Задача | Де |
|--------|-----|
| Підтвердити нового жителя | Заявки / панель очікуваних |
| Змінити статус заявки | Картка заявки |
| Опублікувати новину | Головна → створити новину |
| Тарифи та лічильники | Платежі → тарифи, показання по будинах |
| Надіслати нарахування жителю | Платежі → **«Надіслати»** по будинку |
| Історія змін по будинку | Платежі → історія (аудит за місяць) |

У голови **немає** червоних сповіщень по платежах — він сам їх формує.

**Типовий місячний цикл:** підтвердити реєстрації → новина → обробити заявки → внести тарифи → прийняти показання → надіслати нарахування жителям.

## Додаток на телефон (APK)

1. На сайті: **Ще** → **Завантажити застосунок**.
2. Дозволити встановлення з невідомого джерела (Android).
3. Відкривається той самий сайт у зручній оболонці; логін той самий.

Push-сповіщення в APK поки вимкнені; важливі події краще дублювати в чаті КГ, поки не підключено Telegram-бот.

---

## Чого поки немає

- Оплата взносів **карткою на сайті** (лише облік «оплачено» після переказу).
- Повна заміна месенджерів (чати КГ залишаються для швидких питань).
- Автоматичні SMS / push без налаштування (у планах Telegram та push).
